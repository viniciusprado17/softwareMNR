Como funciona

  1. Para cada bloco, o navegador confere que prev_hash é o hash do bloco anterior (o primeiro aponta para 32 bytes zero).
  2. Recalcula SHA-256(prev_hash ‖ payload ‖ assinatura) e compara com o hash gravado.
  3. Confere a assinatura ECDSA P-256 do payload com a chave pública do nó (WebCrypto do navegador).

Esta conferência roda no seu navegador: não depende do gateway estar honesto. Mesmas regras e mesmos motivos de falha do gateway.

As chaves públicas vêm do próprio arquivo; para confiança total, compare a chave com a registrada no momento da instalação do nó.
